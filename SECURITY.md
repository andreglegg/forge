# Security policy

## Supported versions

Forge is currently a public alpha. Security fixes are made against the latest
published version; older alpha versions may not receive backports.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue for a suspected repository escape, command injection,
credential exposure, permission bypass, unsafe promotion, or supply-chain flaw.

Include the affected version or commit, operating system, reproduction steps,
observed impact, and any proposed mitigation. You should receive an initial
response within seven days. Public disclosure will be coordinated after a fix
or mitigation is available.

The implemented threat boundary and known limitations are documented in
[`docs/SECURITY.md`](docs/SECURITY.md).
